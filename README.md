# Анализатор логов NGINX

Программа-анализатор логов NGINX представляет собой консольную утилиту для автоматической обработки и анализа лог-файлов веб-сервера. Вместо ручного анализа больших объемов логов, утилита автоматически собирает ключевую статистику и генерирует отчеты в различных форматах.
### Что было реализовано

##### 📊 Сбор комплексной статистики
    Общее количество запросов - подсчет всех обработанных запросов
    Анализ размера ответов - средний, максимальный размер и 95-й перцентиль
    Частота кодов ответа - распределение HTTP статус-кодов
    Топ-10 запрашиваемых ресурсов - наиболее популярные URL, отсортированные по убыванию
    Распределение запросов по датам - процентное соотношение запросов по дням с указанием дня недели
    Уникальные протоколы - список всех используемых протоколов передачи данных (HTTP/1.0, HTTP/1.1, HTTP/2, etc.)
    
##### 🌐 Поддержка различных источников данных
    Локальные файлы - работа с отдельными файлами и шаблонами (glob patterns)
    Удаленные файлы - загрузка логов по HTTP/HTTPS
    Форматы файлов - поддержка .log и .txt расширений
    
##### 📅 Гибкая фильтрация по дата
    Фильтрация в указанном диапазоне дат (ISO8601 формат)
    Поддержка различных комбинаций параметров --from и --to
    Включительная фильтрация (границы диапазона включены)

##### 📝 Мultiple форматы вывод
    JSON - структурированный вывод согласно схеме
    Markdown - человеко-читаемые таблицы
    AsciiDoc - расширенный формат документации

##### ⚡ Ключевые особенности
    Потоковая обработка - эффективная работа с большими файлами без загрузки в память
    Обработка ошибок - детализированные сообщения об ошибках с соответствующими кодами возврата
    Валидация входных данных - проверка параметров, форматов файлов и путей
    Качественное логирование - использование log4j для отслеживания работы приложения

### Примеры использования
Анализ локальных файлов
```bash

java -jar log-analyzer.jar \
  --path /var/log/nginx/*.log \
  --format json \
  --output report.json \
  --from 2025-01-01 \
  --to 2025-01-31
```

Анализ удаленных логов
```bash

java -jar log-analyzer.jar \
  --path https://example.com/access.log \
  --format markdown \
  --output analysis.md
```

Анализ с фильтрацией по дате
```bash

java -jar log-analyzer.jar \
  --path logs/access*.txt \
  --format adoc \
  --output report.adoc \
  --from 2025-03-01
```

### Технические характеристики
    Язык программирования: Java 24
    Сборка: Maven
    Тестирование: JUnit 5, покрытие >50%
    Логирование: Log4j 2
    Парсинг аргументов: Picocli
    JSON обработка: Jackson
    Статический анализ: SpotBugs, PMD, Modernizer

### Структура проекта

Проект реализован с модульной архитектурой:
    cli - обработка командной строки
    parser - парсинг лог-файлов
    analytics - сбор статистики
    io - работа с вводом/выводом (локальные и удаленные файлы)
    model - доменные объекты
    enums - перечисления
